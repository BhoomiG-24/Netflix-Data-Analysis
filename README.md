# Netflix Data Analysis using Python

## 📌 Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python. It includes data cleaning, exploratory data analysis (EDA), and visualization to uncover trends in Netflix content.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset
Netflix Movies and TV Shows Dataset (CSV)

## 📊 Tasks Performed
- Imported dataset using Pandas
- Explored dataset structure
- Handled missing values
- Removed duplicate records
- Analyzed Movies vs TV Shows
- Identified Top 10 Countries
- Analyzed Release Year trends
- Analyzed Ratings distribution
- Identified Top Directors
- Saved cleaned dataset

## 📈 Key Insights
- Movies are more common than TV Shows.
- The United States has the highest amount of Netflix content.
- Netflix content increased significantly after 2015.
- TV-MA is one of the most common ratings.
